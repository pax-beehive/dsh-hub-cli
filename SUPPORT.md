## Response targets

Maintainers aim to:

- triage new Issues within two business days;
- provide an initial pull request review within three business days;
- acknowledge complete security reports within three business days; and
- post a status update when an accepted Issue has no activity for 30 days.

These are response targets, not resolution guarantees. Security reports and regressions in the current npm `latest` version take priority.

## Before asking for help

1. Upgrade all four `@dsh-plugin-hub/*` packages to compatible versions.
2. Check the [README](README.md), package documentation, and existing Discussions.
3. Run `dsh-hub --version` and record your Node.js, pnpm, DSH, and operating-system versions.
4. Remove access tokens, refresh tokens, `.env` values, local paths, Profile secrets, and other sensitive data from all output.

The project does not provide private implementation support through personal maintainer accounts.
